[**Provisioning**](https://kubotana.logicmonitor.com/santaba/uiv4/alert#detail~id=LME10863281&type=eventAlert) is the process by which Entra automatically manages identities and roles in cloud applications.
It is distinct from authentication, such as by single sign-on (SSO), which refers to the process of users signing in.

Key to the Microsoft Entra provisioning service is the **System for Cross-Domain Identity Management** (SCIM), a user management protocol and API endpoint provided by the application vendor or provisioning agent.
The SCIM endpoint allows Entra to manage users programmatically.

Applications in the Microsoft Entra gallery support one of two provisioning modes:

- Manual, where there is no automatic Entra provisioning connector
- Automatic, where an Entra provisioning connector allows automatic management of user identities
