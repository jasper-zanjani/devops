Microsoft's SQL Server extension (mssql) (1) for Visual Studio Code is a recommended [replacement](https://learn.microsoft.com/en-us/azure-data-studio/whats-happening-azure-data-studio?tabs=dev) for Azure Data Studio which retires in 2026.
The SQL Server extension also comes bundled with the [SQL Database Projects](https://github.com/Microsoft/azuredatastudio) extension, which integrates with .NET (equivalent to using `dotnet new sqlproj`) and allows management of nested projects.
