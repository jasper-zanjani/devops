List all movies and their ratings in percent

<div class="grid cards" markdown">

```sql title="SQL"
SELECT Title,Rating *10
AS Rating_percent
FROM movies
INNER JOIN Boxoffice
        ON Id == Movie_id;
```

```kusto title="Kusto"
Movies 
| join kind = inner (Boxoffice) on $left.Id == $right.Movie_id
| project Name,Rating_percent = (Rating * 10)

```
