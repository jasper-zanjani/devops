List all movies and their combined sales in millions of dollars

<div class="grid cards" markdown>

```sql title="SQL"
SELECT Title,(Domestic_sales + International_sales)/1e6
AS Total_sales
FROM movies
INNER JOIN Boxoffice
        ON Id == Movie_id;
```

```kusto title="Kusto"
Movies 
| join kind = inner (Boxoffice) on $left.Id == $right.Movie_id
| project Name,Total_sales = (Domestic_sales + International_sales) / 1e6
```
