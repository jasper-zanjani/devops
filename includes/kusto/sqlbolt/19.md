List all the movies by their ratings in descending order

<div class="grid cards" markdown>

```sql title="SQL"
SELECT title, rating
FROM movies
  JOIN boxoffice
    ON movies.id = boxoffice.movie_id
order by Rating desc;
```

```kusto title="Kusto"
Movies
| join kind = inner (Boxoffice) on $left.Id == $right.Movie_id
| sort  by Rating desc
| project Name,Domestic_sales,International_sales
```
