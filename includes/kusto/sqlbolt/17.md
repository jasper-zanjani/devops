Find the domestic and international sales for each movie (1)

1.

<div class="grid cards" markdown>

```sql title="SQL"
SELECT Title, Domestic_sales, International_sales 
FROM movies 
INNER JOIN Boxoffice 
        ON Id = Movie_id;
```

```kusto title="Kusto"
Movies 
| join kind = inner (Boxoffice) on $left.Id == $right.Movie_id 
| project Name,Domestic_sales,International_sales
```
